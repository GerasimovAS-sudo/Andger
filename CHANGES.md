## «Квадрат со свечением» вокруг кольца
Причина (подтверждена по вашему скриншоту: верх «квадрата» ≈ верх SVG-кольца 900×900px): WebKit (Safari/iPhone) обрезает CSS-фильтр
drop-shadow на корневом <svg> по его рамке. Убрано везде, где это было:
- кольцо загрузки (.splash-ring) — свечение теперь HTML-градиентом;
- кольцо таймера практики (.d-timer-ring-svg), аватары (.avt-medal, #profileAva svg), иконки онбординга — фильтр снят с <svg>,
  тень перенесена на HTML-обёртки (box-shadow / filter на div);
- «Путь» (планеты, лента, комета, число в центре) — вместо CSS-фильтров на элементах SVG используется SVG-фильтр url(#ogGlow)
  с запасом области (в Safari CSS-фильтры на элементах SVG не рисуются/обрезаются).

## Нижняя полоса / «не на весь экран» на загрузке (iPhone)
- Загрузчик упрощён: fixed + inset:0 + 100dvh (убраны мои прошлые «заходы за экран», которые на iOS могли давать побочные эффекты).
- Нижний край загрузчика плавно уходит в цвет подложки #120c24, который теперь одинаков у html, manifest (background_color/theme_color)
  и загрузчика — если iOS в первые секунды показывает окно короче экрана, полоса сливается с фоном.
- В режиме PWA после запуска три раза (120/700/1800 мс) переустанавливается meta viewport — это заставляет WebKit пересчитать размеры окна.
- Кэш: в ссылки на CSS/JS добавлен ?v=143, версия service worker v11.11.143, офлайн-кэш учитывает ?v (ignoreSearch).

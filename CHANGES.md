# Vnedri — что изменено (вторая версия)

Распаковать поверх проекта с заменой: app.js, styles.css, design-system.css, index.html, sw.js.
Версия кэша service worker: andger-v11.11.140 (пользователи получат обновление).

## Загрузка на iPhone
- Чёрная полоса снизу: у `#appLoader` было `height: 100%`, а в первые секунды layout-viewport на iPhone короче экрана.
  Теперь загрузчик заходит на 160px ниже экрана (с компенсацией отступа), плюс `min-height: 100dvh` для html/body.
- Квадратная «рамка» вокруг кольца: у SVG кольца был `overflow: hidden`, обрезалось свечение → `overflow: visible`.

## Настройки / админка
- Большой отступ под шапкой: `#settingsScreen .wrap, #adminScreen .wrap { padding-top: 175px !important }`.
  Разделено: настройки 80px, админка 138px.
- (из прошлой версии) чёрные блоки в админке заменены на стекло.

## Главная
- Карточка «Вчера не получилось — это нормально» убрана. Эти слова теперь говорит маскот ANDGER в облачке
  (при пропуске 1 день / 2–3 дня / дольше). Фраза остаётся в ротации подсказок и при тапе по маскоту.
- Баг: интервал подсказок затирал «Действие дня» случайной фразой — исправлено.

## «Путь»
- Лента прогресса со свечением, «голова» с расходящимися кольцами на текущем дне, глянец на пройденных сегментах,
  космическое ядро, орбиты, планеты, звёзды; туманность и дрейфующие звёзды на фоне экрана;
  стеклянные карточки, живая градиентная рамка у карточки «Сегодня», градиентный заголовок недели.

## «Погружение»
- Дышащая сфера с расходящимися кольцами и кольцом прогресса (идёт по предложениям), сияющий анимированный фон,
  стеклянная карточка, текст проявляется с эффектом размытия. Для низких экранов — компактный вариант.

## Аватары
- Единая премиальная линейка медальонов (+5 необычных).
- НОВОЕ: портреты — Ария, Лео, Мира, Кай (бесплатные), Хранитель, Монах, Нова, Феникс (в магазине).
- В выборе закрытые аватары больше не «чёрные пятна»: приглушённый тизер + плашка с ценой.

## Порядок в коде (проверено попиксельно по 30 экранам: отличий нет)
- CSS: удалено 421 правило + 27 селекторов, у которых классы/id нигде не встречаются (JS, HTML, данные), 3 неиспользуемых @keyframes,
  дубли. styles.css 175→135 КБ, design-system.css 76→63 КБ. Список удалённого — removed_css.txt.
- JS: удалено 43 неиспользуемые функции (старая админка, дубли back*, sendResetSms, redeemPromo, tapMascot и др.). app.js −23 КБ.
- Защита: ensureSlug не падает, если у профиля нет телефона.

## Баги из прошлой версии (остались в силе)
- goToRating() добавлена; тост ошибок соединения работает; анимации экранов; reduced-motion учитывается.

## Что НЕ делалось
- Звуки/вибрация уже работали глобально на клике — их логика не менялась.
- Сам по себе дублирующий CSS с разными значениями (каскад «патчей») не сливался — это рискованно без полной регрессии;
  мёртвое удалено, живое оставлено.
- Проверка шла на заглушке Supabase и в Chromium; iPhone Safari воспроизвести нельзя — проверьте полосу на устройстве.
